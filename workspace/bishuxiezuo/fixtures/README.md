# Test Fixtures（E02/E03 测试数据生命周期）

约定（Batch 4.2/4.3，用户确认的三原则）：

1. **专用测试书籍**：`WBTEST-E02`（世界观编辑）、`WBTEST-E03`（角色管理），通过网站 UI 创建，不碰真实书籍，不写数据库
2. **不使用 AI 重新生成**（避免额度消耗与不可控结果）
3. **FIFO 纪律**：重新采集同签名请求前，必须确认测试数据当前所处业务状态；不同状态下不随意重复采集，防止多版本响应混入错误业务态
4. **回放语义**：创建/修改 API 是有状态的，v2.3 是静态回放——必须整链采集（POST 创建 → PUT 修改 → GET 终态快照），才能离线验证页面行为；回放 201 ≠ 真实持久化

## 清理方式

测试书籍通过网站 UI 删除（如果支持）；删除前先导出本目录快照。真实书籍《全球高武》永不触碰。
