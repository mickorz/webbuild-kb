常见问题 · FAQ

你大概会问的
几个关键问题。

两者本就不是从属关系。我们有专门的导演 Agent 与冲突裁决 Agent 协调走向，你也可以随时介入拍板。而且很多时候——碰撞本身就是最大的看点。世界的"不配合"，往往逼出比预设更精彩的转折。
完全不用。笔枢有两种写作模式：Auto Driver 全自动碰撞——世界状态机与导演自由推演、整章涌现；协同审校——你在任意节点接管，而审校与改稿同样有 Agent 辅助：给方向，不必逐字。两种模式之间连续可调。
这是冰山理论。读者和主角看不到、故事里还没出场，不代表事件没有发生。水面之下完整运转的世界，才让水面之上的每一次转折都"有来由"——而不是临时编造。
我们不在"AI 写得像不像人"那条赛道上。笔枢做的是世界模拟——你得到的不是一个写手，是一台让故事自洽涌现的引擎。
世界状态机每章做一致性校验，分层长期记忆让近处清晰、远处凝练、需要时精准检索。百万字也守得住设定与伏笔。
