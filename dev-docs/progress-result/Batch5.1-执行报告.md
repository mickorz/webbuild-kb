## 白名单核实的真实来源

S01-S05 各一条 `query-variant-fallback /console/console.css?v=...`：镜像 HTML 经人工定制带版本号后缀（见经验文档），请求 query 与归档录制值不一致，pathname 单候选回退拿到**正确的** CSS。已作为已知良性依赖登记进五个页面场景——这正是白名单的价值：隐性依赖显式化，新增回退立即红。
